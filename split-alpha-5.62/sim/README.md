# 武器の試算の道具（split-alpha-5.62/sim）

`split-alpha-5.62/index.html` の戦闘の決まりをそのまま写して、自動で戦わせ、武器の強さを比べる道具です。
Node だけで動きます（新しいパッケージは不要）。ゲーム本体は読むだけで、変更しません。

## ファイル
| ファイル | 中身 |
|---|---|
| `engine.js` | 戦闘の決まり（index.html の関数を写したもの）と、味方の動かし方 |
| `weapons.js` | 試算用の武器18本と基準の武器。武器の効果はここに書く |
| `run.js` | 全条件をまとめて回し、`output/` に結果を書き出す |
| `verify_against_page.js` | 道具の行動を本物のページで再生し、毎ターンの状態が一致するか確かめる（Playwright を使う。この環境には最初から入っている） |
| `output/results.md` | 結果の表（今のボス・3倍のボス） |
| `output/results.json` | 同じ結果の数値 |
| `output/sample-log.txt` | 1戦分のすべての行動の記録 |
| `output-boss10/` | 参考：HP・壊れる量10倍のボスでの結果 |

## 動かし方
リポジトリの `split-alpha-5.62` フォルダで:

```
node sim/run.js                                   # 全条件（各500戦）→ sim/output/
node sim/run.js --battles 200                     # 戦う回数を変える
node sim/run.js --only m-rare,k-epic              # 一部の武器だけ（基準はいつも測る）
node sim/run.js --bosses 10 --out output-boss10   # ボスの倍率（HPと壊れる量）と出力先を変える
node sim/run.js --log m-mythic --policy defense --boss 3 --quality 5 --seed 1000
                                                  # 1戦の全記録を画面に出す（--log base で基準の武器）
node sim/verify_against_page.js 6                 # 本物のページとの照合（各条件6戦）
```

- 乱数の種は `--seed0`（初期値1000）から順に使います。同じ条件なら毎回同じ結果になります。武器が違っても同じ種を使うので、武器の差だけが比べられます。
- ターンの上限は `--max-turns`（初期値100）。上限まで決着しなかった戦は「勝てなかった」として数えます。

## 武器を足す・変える手順
1. `weapons.js` の `WEAPONS` に1行足す。最低限 `key`（例 `m-new`）、`owner`（`m`/`r`/`k`）、`rarity`、`name`、`min`、`max`、`ch`（必要チャージ）を書く。
2. 効果は次の差し込み口で書く（`b` は戦闘、`c` は持ち主）。
   - `maxHp`：最大HPに足す数
   - `guardBonus`：盾のカードで得る盾に足す数
   - `plague: true`：持ち主が付ける毒をすべて疫毒にする
   - `cardBonus(b,c,card)`：カード攻撃のダメージに足す数（凍傷の前に足す）
   - `cardDamage(b,c,part,damage)`：カード攻撃の最終ダメージを書き換える（壊れた部位の1.2倍の前）
   - `afterCardHit(b,c,part,damage,result)`：カード攻撃が当たったあと
   - `afterCard(b,c)`：カードを使い終わったあと（Costの確認など）
   - `fire(b,c)`：武器技の中身（書かなければ「基礎値を、選んだ部位に1回」）
   - `afterFire(b,c)`、`endPlayerPhase(b,c)`、`newTurn(b,c)`、`init(b,c)`
   - 戦闘側の便利な関数：`b.choosePart()`（狙う部位を決める）、`b.hitPart(量,持ち主,部位,{noBroken,skipBreak,breakAmount})`、`b.addBreak(部位,量)`、`b.addPoison(c,部位,数)`、`b.forecastTo(id)`（その子への予告ダメージ合計）、`b.attackTargetsAny(id)`（狙われているか）、`b.log(文)`
3. `node sim/run.js --only 新しいkey` で測る。`--log 新しいkey` で1戦の記録を見て、効果が思ったとおりに動いているか確かめる。
4. ゲーム本体の決まりや数字が変わったら、`engine.js` を合わせて直し、`node sim/verify_against_page.js` で本物のページと一致するか確かめる。

## コードから読み取った決まり（index.html）
- **手札：** 各キャラの最初の4枚だけ（美桜 M1〜M4、麗華 R1〜R4、小春 K1〜K4）。カードは使っても無くならず、Costがあれば同じカードを何度でも使える。Costは毎ターン3に戻る。
- **チャージ：** 使ったカードのCost分だけ増え、必要チャージで止まる（`play`）。撃つと0（武器技ボタンの処理）。武器技はCostを使わず、凍傷・火傷の補正も受けない。
- **カード攻撃のダメージ：** `modifiedDamage`（自分の凍傷を引き、相手の火傷で増やして四捨五入）。
- **逆上・庇護の怒り：** 敵の部位に固定で入っている `target`（禍='m'、呪='r'、灰='k'）を見ている。そのため、ほぼいつも＋20になる。予告の狙いとは関係しない。
- **部位を攻撃すると：**
  - 共有HPが減る。壊れた部位には1.2倍で、`Math.round`（四捨五入）。
  - 壊れていない部位には、壊れる量がたまる。
  - 壊れると、その部位はそのターンの攻撃が止まる。予兆も最初からやり直し。
- **敵の攻撃：** 予兆でない部位が、保存した相手を狙う。味方ごとに合計してから盾を1回引く。状態異常は実際にHPが減った子にだけ付く。
- **毒：** 敵の部位ごと（`foe.poison`）にたまり、減らない。敵フェーズの終わりに、部位ごとにその数だけ共有HPを減らす。味方の毒も減らず、毎ターン始めにその数だけHPが減る。

## 推測で決めた所（コードに無い・はっきりしない所）
1. **味方が動く順番：** 毎ターン 美桜 → 麗華 → 小春。
2. **カードの選び方：** 「(ダメージ + 毒の数×3) ÷ Cost」が一番大きいカード。同じなら、ダメージが大きい方、次にカードの順番が早い方。毒1つを3ダメージとみなすのは仮の値で、疫毒なら6とみなす。
3. **攻撃カードと盾カードの分け方：** 盾が付くカード（反骨・揺るがぬ余裕・茨の盾）を盾カード、それ以外を攻撃カードとした。格の違い（敵の攻撃を軽減）も攻撃カードに入る。
4. **守り優先：** その子の番の始めに、狙われていて予告ダメージの合計が10以上なら、盾カードを1枚だけ先に使う。予告の合計は、その時点の値（前の子の軽減が反映される）。
5. **攻め優先の盾カード：** Costが余って攻撃カードが使えないときだけ使う。手札にはCost1の攻撃カードがあるので、実際にはほぼ使われない。
6. **狙う部位：**
   - 壊れた部位があればそこを狙う。2つ以上あれば番号が小さい方。
   - 無ければ「壊れる量の割合」が一番大きい部位。同じなら、残りが少ない方、次に番号が小さい方。
7. **武器技を撃つ確認：** 撃てるかの確認は、その子の番の最初と、カードを1枚使うたびに行う。
8. **ターンの上限：** 100。
9. **カード攻撃に足す数**（逆棘＋8、護衛＋4、深翠＋8、食い込み＋3×数）：凍傷で引く前に足す。
10. **往復刃：**
    - 追撃 ＝ そのカード攻撃の最終ダメージ（凍傷のあと、1.2倍の前）÷3、切り捨て。
    - 同じ部位への別の攻撃として扱う。壊れた部位なら1.2倍、壊れる量にも入る。
11. **食い込みの鋸：**
    - カード攻撃に足す数は、そのカードを使う時点の数で決める。
    - 武器技では、今の数×10を足してから0にし、その武器技の1発でまた1つたまる。
12. **双刃・群針：** 1発ごとに狙う部位を決め直す。
13. **銀線のリボルバー：**
    - 印は、撃ったターンの次のターンの、味方の番の終わりまで続く。
    - ＋30％は最終ダメージに切り捨てで足し、1.2倍の前にかける。
    - 3回は、印の付いた部位に麗華のカード攻撃が当たった回数で数える。
14. **蓄圧リボルバー：** カードを使ったあとでCostが0になっていれば、チャージ＋1（1ターン1回）。
15. **威圧のリボルバー：**
    - ＋60％には「盾30以上」と「狙われていて、盾が予告の合計以上」の両方が要るとした。
    - 予告の合計は、撃つ時点の値。
16. **女王の追撃銃：**
    - 2発目は同じ部位に撃つ。
    - 壊れた部位の1.2倍は2発目にもかかる（1発目で壊れた場合も）。
    - 2発とも壊れる量に入る。
17. **散華の針束：**
    - 毒は付かない。
    - 共有HPの減り分は、すべて小春の与ダメとして数える。
    - 壊れる量で部位が壊れたら、普通と同じく、その部位のそのターンの攻撃も止まる。
18. **武器技の毒：** 当てた部位に付ける（毒は部位ごとというコードに合わせた）。群針は、1本ごとに当たった部位へ＋2。
19. **疫毒：**
    - 部位ごとに数える。毎ターン「毒＋疫毒×2」を、毒と同じ時に削る。
    - 疫病の原針で疫毒になるのは、小春のカードで付く毒（小春が付ける毒はこれだけ）。
20. **毒と疫毒のダメージ：** すべて小春の与ダメとして数える（今の手札で毒を付けるのは小春だけ）。
21. **再点火のソー：** 武器技を撃った直後にCost＋1。美桜の番の最初に撃った場合も同じ。
22. **最大HP＋10：** 戦いの始めのHPも＋10。
23. **基準の武器：** 品質で変わらない（美桜100・麗華110・小春100、必要チャージ6）。
24. **端数：** 武器の効果の割合はすべて切り捨てにした。ただし、ゲーム本体の壊れた部位の1.2倍と火傷は、コードどおり四捨五入のまま。「端数はすべて切り捨て」との食い違いあり。
25. **数え方：**
    - 「平均ターン」は勝った戦だけの平均。
    - 「与ダメ/T」は、持ち主の与ダメ（共有HPが実際に減った量）を、その戦のターン数で割って平均したもの。
    - 「終了時の味方平均HP」は、3人のHP（倒れた子は0）の平均を、全戦で平均したもの。
    - 「基準比」は、与ダメ/T を同じ持ち主の基準の武器と比べた値。
26. **乱数：** ゲームの `Math.random` の代わりに、種を固定した乱数（mulberry32）を使う。ゲームで乱数を使うのは、敵が狙う相手を選ぶ所だけ。

## 照合（verify_against_page.js）
基準の武器で、道具の行動を本物のページ（index.html）で同じ乱数のまま再生します。毎ターンの始めに、次の数字を比べます。

- 共有HP
- 味方：HP・盾・Cost・チャージ・毒・状態異常
- 部位：壊れる量・壊れたか・止まっているか・予兆の残り・毒・狙う相手

武器18本の効果はゲームに無いので、照合できません。効果が思ったとおりに動いているかは、`--log` の記録で確かめてください。

## 結果を読むときの注意（第2段階で分かったこと）
- **4ターン目の部位破壊：**
  - 基準の条件では、勝ち負けが「最初の部位破壊（いつも禍）が4ターン目か」でほぼ決まる。

## 第3段階で推測で決めた所
1. **的の「HPが0になっても続ける」：** 共有HPを 10^12 にして実現した。倒した時にダメージが切り捨てられないので、「0の先まで減らす」のと同じになる。
2. **的の味方：** HPを減らさない。状態異常は、ゲームの決まり（HPが実際に減ったときだけ付く）のとおり付かない。盾も減らさない（次のターンに0に戻るので結果は同じ）。
3. **累計ダメージの時点：** 「3・6・10ターン目の時点」は、そのターンの敵フェーズの毒まで含めた累計にした。
4. **動かし方を変える変更案の基準比：** 盾カードを先に使う・毒をためるといった変更案も、その動かし方を入れていない基準の武器と比べた。動かし方だけの効果は、対照の行（基準の武器＋その動かし方）で見る。
5. **条件2の置き換え：**
   - 「禍の普段の攻撃」は、禍で一番多い「1人を狙う攻撃」にした（4ターンのうち2ターンがこれ）。
   - 狙う相手は普段どおり乱数で選ぶ。乱数を1回多く使うので、その後の乱数の並びは今のコードとずれる。
   - ダメージ（12）と、そのターンの状態異常（偶数ターンなのでスタン）は、コードのまま。つまり、置き換えた攻撃でも1人はスタンすることがある。
6. **外した攻撃：** 禍だけ。灰も2・6ターン目などに全員を狙うが、付くのは凍傷・毒なので外していない。呪の全員攻撃の番は、呪が攻撃しないターンに当たるので、実際には出ない。

## 第2段階の書き方の訂正
第2段階で「必要チャージ5と6、7と8はほぼ差が出ない」と書いたのは、8ターン前後で決着する戦いの中での話でした。

- チャージは1ターン3たまり、撃ったあとの余りも持ち越されます。
- そのため10ターンでは、必要チャージ5で6回、6で5回撃てます。7は4回、8は3回です。
- 長い戦いでは差が出ます（条件1の表で確かめられます）。
